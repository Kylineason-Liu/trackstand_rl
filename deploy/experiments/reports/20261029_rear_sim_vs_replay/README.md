# Rear-wheel simulation versus hardware replay

Three vertically aligned panels, **two response curves per panel**: actuator torque
in Nm, angular velocity in rad/s, and unwrapped startup-relative position in rad.
Blue is saved Isaac Lab 400 Hz simulation; orange is the airborne hardware replay.

- **[50 Hz comparison](rear_sim_vs_replay_50hz.png)** — [SVG](rear_sim_vs_replay_50hz.svg), [PDF](rear_sim_vs_replay_50hz.pdf).
- **[200 Hz comparison](rear_sim_vs_replay_200hz.png)** — [SVG](rear_sim_vs_replay_200hz.svg), [PDF](rear_sim_vs_replay_200hz.pdf).
- [Gallery](index.html), [plotted native samples](plotted_samples.csv), [statistics and input hashes](statistics.json).

Both use the same model_2500 Isaac-recorded torque sequence from episode time
12.5–17.5 s, held at 50 Hz. The figure shows replay time 2–7 s with its horizontal
axis relabeled 0–5 s. No fitted response delay, bias removal, smoothing or vertical
offset was applied. Hardware uses actual fresh A1/A2/A3 samples, not cached state.

The simulation is the prior nominal fixed-base, airborne replay, case
`isaac400_dr_env0_12p5_17p5_friction_on`, index 4. The input policy was DR-trained;
this actuator replay itself has nominal plant parameters and no DR resampling or
policy inference. Its first 350 rear targets exactly match each hardware plan.

Torque compares simulation **submitted actuator effort before passive joint
friction** with hardware **signed A1 current × measured B0 Kt**. Simulation solver
joint-axis effort is not used: it is a different quantity. Neither plotted curve
is independently measured net wheel torque after all losses.

Position retains full revolutions. Hardware subtracts its own startup A3 multi-turn
count with encoder sign −1. Simulation sums native before/after position increments
at every physics step, resolving the PhysX 4π branch. It is not wrapped at ±π,
and is not generated by integrating velocity. Neither position is rebased at the
five-second plot boundary. The last hardware point precedes the exact endpoint
slightly because feedback is asynchronous.

| Core measurement | Isaac400 | Hardware 50 Hz | Hardware 200 Hz |
| --- | ---: | ---: | ---: |
| Peak backward speed | 21.398 rad/s | 8.049 rad/s | 2.833 rad/s |
| Last plotted displacement | −33.290 rad | −5.282 rad | −0.335 rad |

These curves illustrate similar actuator-level torque with substantially different
motion. Real support/actuator dynamics and starting wheel phase are not fully
matched to simulation. They do not isolate a cause, prove intrinsic randomness or
establish a universal packet-rate ranking. The hardware captures are the original
October 26 runs; no new hardware or simulation was operated for these figures.

Reproduce from the repository root:

```bash
python3 -B deploy/experiments/reports/20261029_rear_sim_vs_replay/plot_comparison.py
```

The read-only data path independently checks raw CAN units/signs against saved
columns, completion/cleanup, monotonic feedback times, exact simulator/plan target
equality and simulator position continuity. Original inputs are unchanged.
