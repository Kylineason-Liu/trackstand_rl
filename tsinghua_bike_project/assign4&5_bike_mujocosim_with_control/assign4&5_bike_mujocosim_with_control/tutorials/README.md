# 自行车平衡控制：从零开始的七讲实验课

这套 notebook 面向没有系统学习过自行车动力学或控制理论的学生。建议严格按顺序学习；每讲都能独立运行，但后面的概念会复用前面的符号和结论。

1. `01_自行车为什么会倒_建模与开环.ipynb`：角度、角速度、状态、线性模型、开环不稳定。
2. `02_反馈是什么_PD与采样控制.ipynb`：负反馈、P/PD、转向回正、饱和、50 Hz 采样。
3. `03_极点配置_从期望动态到反馈增益.ipynb`：特征值、可控性、极点配置、速度增益调度。
4. `04_LQR_在平衡性能与控制能量之间权衡.ipynb`：二次型代价、Q/R 整定、扰动与方法比较。
5. `05_数字控制_采样执行器饱和与噪声.ipynb`：离散化、零阶保持、执行器内环、抗饱和与滤波。
6. `06_IMU安装误差_坐标标定与状态构造.ipynb`：IMU—车体轴不重合、陀螺零偏、多轴安装标定、姿态旋转和控制状态构造。
7. `07_MuJoCo实战_50Hz双环自行车平衡.ipynb`：IMU 坐标修正、外环状态反馈、内环 PI、MuJoCo 闭环仿真和视频。

## 推荐学习方式

- 先从菜单执行“重启内核并运行全部单元格”，确认环境正常。
- 再从头阅读文字，并在练习单元格中修改参数。
- 每次只改一个参数，同时观察滚转角、转向速度和控制量。
- 不要只判断“有没有倒”，还要比较最大滚转角、收敛时间和控制峰值。

所有角度在计算中使用弧度；只有绘图时转换为度。教程使用 50 Hz 控制周期，MuJoCo 物理积分仍保持 XML 中的 0.5 ms。

实车实验前必须先完成第 6 讲的坐标轴方向、安装旋转和陀螺零偏标定。滤波不能补救坐标系定义错误。

## 环境依赖

建议使用项目当前的 Python 3.12 环境。教程需要 `numpy`、`scipy` 和 `matplotlib`；第 7 讲还需要 `mujoco` 和 `mediapy`。若 notebook 无法导入项目模块，请确认 Jupyter 的工作目录是项目根目录或 `tutorials/` 目录，并确认所选内核与安装依赖的 Python 环境一致。
