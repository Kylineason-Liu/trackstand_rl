# 遥控器调试

我们有一个Hot RC 10A 遥控器，树莓派需要接收遥控器的命令

遥控器的信号将传输给SBUS接收器，SBUS接收器则会以SBUS的协议输出信号，我们需要使用一个SBUS转USB的模块，实现将SBUS中的信号进行解码，并传输给树莓派

## 资料清单

1. Remote Controller lease doc
   包含了遥控器的说明文档，以及SBUS接收机如何与遥控器配对的说明文档
2. USB-SBUS
   包含了要更改USB-SBUS模块参数时的上位机，以及USB-SBUS模块的使用手册


## 任务

这是最后一个硬件的调试，需要大家阅读配件原始的资料进行开发。

SBUS-USB模块的默认波特率是115200，可以根据以上资料编写ROS2接收遥控器指令的代码。

如果我们最后把接收到的遥控器指令，再转换成其他硬件的ROS2 Topic接口对应的消息发出去，就能最终实现使用遥控器来遥控小车了。
