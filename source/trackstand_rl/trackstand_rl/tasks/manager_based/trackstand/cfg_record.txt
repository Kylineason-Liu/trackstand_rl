2. The SDF-on-both contact representation (Isaac Lab side)
----------------------------------------------------------
- URDF import pipeline (URDF USD Converter v0.1.2): every link becomes two
  instanced Xforms — <link> (visual) and <link>_1 (collision). The collision
  mesh child (inside an instanced prototype, INVISIBLE to plain stage
  traversal) carries PhysicsCollisionAPI + physics:approximation="convexHull"
  + purpose="guide" (these are the colliders that "collision from visuals"
  deletes — the old model-breaking import behavior).
- CRITICAL FINDING: setting physics:approximation="sdf" ALONE does nothing —
  the PhysX parser rejects the unknown token and falls back to convexHull
  (the "falling back to convexHull" error, reproduced headless + in the GUI).
  The SDF branch is gated on applying PhysxSDFMeshCollisionAPI to the
  collision prim. With token + API the fallback error disappears (verified
  in 5+ consecutive headless app runs).
- Evidence in the binary (omni.physx 110.1.11): fillSdfTriangleMeshDesc,
  SdfMeshCookingParams, Gu::SDFContactReduction, Gu::SDFUsingWindingNumbers —
  the full SDF contact pipeline is present; the schema ships
  PhysxSDFMeshCollisionAPI (sdfResolution 256, sdfSubgridResolution 6,
  BitsPerPixel16, sdfNarrowBandThickness 0.01, sdfMargin 0.01).
- apply_wheel_sdf.py (in the _sdf description package) patches the imported
  USD at the Sdf level: approximation="sdf" + apiSchemas prepend +
  resolution/margin on the two wheel collision overs in
  payloads/instances.usda. USD forbids authoring through instance proxies,
  so the edit targets the payload-layer spec via its prim stack.
- Geometry comparison (from disk): MuJoCo 0914 collision00.stl = 9,372 tris
  (7.4x decimated!) vs its visual 69,732 tris; the Isaac SDF is cooked from
  the FULL tire STL (69,728 tris — the same mesh as the MuJoCo visual), grid
  spacing ~0.55 mm (AABB/256) + ~1.4 mm margin. => the SDF side is now finer
  than the MuJoCo side; the remaining geometric gap is dominated by the
  MuJoCo collision00 decimation, not by PhysX.
- Headless-probe infrastructure notes (reusable): kit --exec scripts swallow
  python stdout (write results to a file); asyncio.run deadlocks (use
  synchronous app.update() pumping); omni.usd.get_world_transform_matrix for
  poses; the scene-query raycasts never wired up headless (floor sanity ray
  always missed); pxr.PhysxSchema imports only inside the full app.
